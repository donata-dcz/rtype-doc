# The server

One computer runs the server, and every player connects to it with the client.

## Download

Pre-built versions for **Linux** and **Windows** are on the [releases page](https://github.com/alexis801/RType/releases). Download the archive for your system from the latest release and unzip it.

## Network

The server listens on **UDP port 4242**. If it runs on another computer, make sure that its firewall lets UDP traffic through on this port (or on the one you choose with `-p`).

## Next step

[Launch the game](../Launch.md). You also need a [client](Client.md) that players run to connect to the server.
