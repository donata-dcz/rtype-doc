# The server

One computer runs the server, and every player connects to it with the client.

## Download

Choose the archive for your system, then unzip it.

=== "Windows"

    [Download for Windows (x64)](https://github.com/donata-dcz/rtype-doc/releases/download/v2/r-type-windows-x64.zip){ .md-button .md-button--primary }

=== "Linux"

    [Download for Linux (x64)](https://github.com/donata-dcz/rtype-doc/releases/download/v2/r-type-linux-x64.tar.gz){ .md-button .md-button--primary }

## Network

The server listens on **UDP port 4242**. If it runs on another computer, make sure that its firewall lets UDP traffic through on this port (or on the one you choose with `-p`).

## Next step
